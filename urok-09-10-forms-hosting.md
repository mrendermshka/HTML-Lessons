- Рівень: початковий

- Технології: `HTML` + `CSS`
- Додатково: знайомство з `GitHub Pages`

---

## Мета уроку

На цьому уроці учні:
- дізнаються, що таке HTML-форма;

- опублікують свій сайт у мережі за допомогою GitHub Pages.

## Частина 1. Теорія

### 1. Що таке форма

Форма — це частина сайту, у якій користувач може щось ввести.

Наприклад:
- своє ім'я;
- вік;
- улюблену гру;
- повідомлення;
- відповідь на запитання.

Форми часто використовуються:
- для реєстрації;
- для анкет;
- для зворотного зв'язку;
- для опитувань.

---

### 2. Головний тег форми — `<form>`

Тег `<form>` об'єднує всі поля форми в один блок.

#### `index.html`
```html
<form>
    <label>Твоє ім'я</label>
    <input type="text">
</form>
```

Усередині форми ми можемо розміщувати:
- підписи;
- поля для введення;
- кнопки;
- великі текстові поля.

---

### 3. Тег `<label>`

`<label>` — це підпис до поля.

Він пояснює, що саме потрібно ввести.

#### Приклад
```html
<label>Твоє ім'я</label>
<input type="text">
```

Без `label` людині важче зрозуміти, для чого потрібне поле.

---

### 4. Тег `<input>`

`<input>` — це поле для введення.

У нього бувають різні типи.

#### `type="text"`
Для звичайного тексту.

```html
<input type="text">
```

#### `type="number"`
Для числа.

```html
<input type="number">
```

#### `type="email"`
Для електронної пошти.

```html
<input type="email">
```

#### `type="checkbox"`
Для позначки.

```html
<input type="checkbox">
```

---

### 5. Атрибут `placeholder`

`placeholder` показує підказку всередині поля.

#### Приклад
```html
<input type="text" placeholder="Введи своє ім'я">
```

Це зручно, бо учень одразу бачить, що треба написати.

---

### 6. Тег `<textarea>`

`<textarea>` — це велике поле для тексту.

Воно зручне, якщо потрібно написати кілька речень.

#### Приклад
```html
<textarea placeholder="Напиши щось про себе"></textarea>
```

---

### 7. Тег `<button>`

Кнопка потрібна, щоб натиснути й відправити форму або просто завершити введення.

#### Приклад
```html
<button>Відправити</button>
```

---

### 8. Приклад простої форми

#### `index.html`
```html
<form class="my-form">
    <label>Твоє ім'я</label>
    <input type="text" placeholder="Напиши ім'я">

    <label>Скільки тобі років?</label>
    <input type="number" placeholder="Напиши вік">

    <label>Твоя улюблена гра</label>
    <input type="text" placeholder="Напиши назву гри">

    <label>Напиши щось про себе</label>
    <textarea placeholder="Я люблю..."></textarea>

    <button>Готово</button>
</form>
```

---

### 9. Стилізація форми через CSS

#### `style.css`
```css
.my-form {
    display: flex;
    flex-direction: column;
    gap: 12px;
    max-width: 400px;
    background-color: white;
    padding: 20px;
    border-radius: 14px;
    box-shadow: 0 4px 10px rgba(0, 0, 0, 0.1);
}

.my-form input,
.my-form textarea {
    padding: 10px;
    border: 1px solid #cbd5e1;
    border-radius: 10px;
    font-size: 16px;
}

.my-form button {
    background-color: #4f46e5;
    color: white;
    border: none;
    padding: 12px;
    border-radius: 10px;
    cursor: pointer;
}
```

Тепер форма буде не просто працювати, а ще й виглядати красиво.

## Частина 3. Що таке хостинг

### Просте пояснення

Хостинг — це місце, де сайт "живе" в інтернеті.

Поки файл `index.html` лежить тільки у тебе на комп'ютері — бачиш його лише ти.

Коли ми викладаємо сайт на хостинг, ним можна поділитися через посилання.

На цьому уроці ми будемо використовувати **GitHub Pages**.

---

## Частина 4. GitHub Pages

### Що таке GitHub Pages

`GitHub Pages` — це безкоштовний спосіб опублікувати простий сайт.

Він добре підходить для:
- навчальних сайтів;
- власних сторінок;
- маленьких проєктів.

---

## Покроково: як опублікувати сайт

### Крок 1. Створити репозиторій
1. Зайди на сайт **GitHub**.
2. Увійди у свій акаунт.
3. Натисни кнопку **New repository**.
4. Введи назву репозиторію.
5. Натисни **Create repository**.

**Скріншот 1:** створення нового репозиторію  
_Додати скріншот екрана GitHub з кнопкою “New repository”._

---

### Крок 2. Завантажити файли сайту
1. Відкрий створений репозиторій.
2. Натисни **Add file**.
3. Обери **Upload files**.
4. Перетягни туди `index.html` і `style.css`.
5. Натисни **Commit changes**.

**Скріншот 2:** завантаження файлів  
_Додати скріншот сторінки Upload files._

---

### Крок 3. Увімкнути GitHub Pages
1. Відкрий вкладку **Settings** у репозиторії.
2. Знайди розділ **Pages**.
3. У полі **Build and deployment** вибери:
   - **Deploy from a branch**
4. Обери гілку:
   - `main`
5. Натисни **Save**.

**Скріншот 3:** налаштування GitHub Pages  
_Додати скріншот розділу Pages у Settings._

---

### Крок 4. Отримати посилання на сайт
Після цього GitHub створить посилання на твій сайт.

Воно буде приблизно таким:

```text
https://your-name.github.io/repository-name/
```

**Скріншот 4:** готове посилання на сайт  
_Додати скріншот блоку, де з'являється URL сайту._

## Типові помилки

### У формі
- забули тег `<form>`;
- немає `label`;
- не закрили `textarea`;
- форма злилась в один блок без відступів.

### Під час публікації
- завантажили не ті файли;
- назвали файл не `index.html`;
- не ввімкнули GitHub Pages;
- сайт не відкривається одразу, бо GitHub ще не встиг його зібрати;
- забули натиснути `Save` у розділі Pages.

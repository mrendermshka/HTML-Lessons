- Рівень: початковий
- Формат: 50% пояснення, 50% практика

---

## Мета уроку

На цьому уроці учні:
- навчаться будувати структуру справжньої вебсторінки;
- дізнаються, для чого потрібні `header`, `main`, `section`, `footer`;

---

## Частина 1. Теорія

### 1. Що таке структура сторінки

Коли ми відкриваємо сайт, то бачимо не випадковий набір тексту, а сторінку, у якої є певні частини.

Зазвичай вебсторінка має:
- верхню частину;
- головний вміст;
- окремі блоки з інформацією;
- нижню частину.

У HTML для цього є спеціальні теги. Вони допомагають:
- браузеру зрозуміти сторінку;
- людині легше читати код;
- правильно будувати сайт.

Простими словами:
HTML показує, **де яка частина сторінки знаходиться**.

---

### 2. Головні теги структури сторінки

#### `<header>`

Тег `<header>` — це верхня частина сторінки.

Тут часто знаходяться:
- назва сайту;
- логотип;
- меню;
- короткий опис.

#### `<main>`

Тег `<main>` — це головна частина сторінки.

Саме тут знаходиться основний зміст:
- текст;
- картинки;
- картки;
- списки;
- інформаційні блоки.

#### `<section>`

Тег `<section>` — це окремий змістовний блок.

Наприклад:
- блок “Про мене”;
- блок “Мої улюблені ігри”;
- блок “Моє хобі”.

#### `<footer>`

Тег `<footer>` — це нижня частина сторінки.

У футері часто пишуть:
- ім'я автора;
- рік;
- контакти;
- невеликий підпис.

---

### 3. Приклад простої структури сторінки

#### `index.html`
```html
<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Мій сайт</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <header>
        <h1>Мій сайт</h1>
        <p>Ласкаво прошу на мою сторінку!</p>
    </header>

    <main>
        <section>
            <h2>Про мене</h2>
            <p>Я люблю створювати сайти та малювати.</p>
        </section>

        <section>
            <h2>Моє хобі</h2>
            <p>Мені подобається Minecraft і створення власних світів.</p>
        </section>
    </main>

    <footer>
        <p>2026 Мій навчальний сайт</p>
    </footer>
</body>
</html>
```

У цьому прикладі:
- у `header` знаходиться назва сторінки;
- у `main` — головний текст;
- у `section` — окремі блоки;
- у `footer` — нижній підпис.

---

### 4. Що таке Flexbox

`Flexbox` — це спеціальний спосіб розкладати елементи на сторінці.

Він потрібен, коли ми хочемо:
- поставити елементи в один ряд;
- зробити меню;
- красиво розташувати картки;
- зробити відстань між блоками.

Без `Flexbox` елементи часто стоять один під одним. З `Flexbox` їх можна розкласти так, як потрібно.

---

### 5. Головні властивості Flexbox

#### `display: flex`

Вмикає `Flexbox` для блоку.

#### `flex-direction`

Показує, як будуть стояти елементи:
- `row` — у ряд;
- `column` — у колонку.

#### `justify-content`

Керує розташуванням елементів по горизонталі.

Наприклад:
- по центру;
- зліва;
- з відстанню між ними.

#### `align-items`

Керує розташуванням елементів по вертикалі.

#### `gap`

Робить відстань між елементами.

---

### 6. Простий приклад Flexbox

#### `index.html`
```html
<div class="cards">
    <div class="card">Картка 1</div>
    <div class="card">Картка 2</div>
    <div class="card">Картка 3</div>
</div>
```

#### `style.css`
```css
.cards {
    display: flex;
    gap: 20px;
}

.card {
    background-color: lightblue;
    padding: 20px;
    border-radius: 12px;
}
```

У цьому прикладі:
- `.cards` — це батьківський блок;
- `display: flex` ставить картки в ряд;
- `gap: 20px` додає відстань між ними.

---

### 7. Меню через Flexbox

Меню сайту дуже зручно робити за допомогою `Flexbox`.

#### `index.html`
```html
<nav class="menu">
    <a href="#">Головна</a>
    <a href="#">Про мене</a>
    <a href="#">Галерея</a>
    <a href="#">Контакти</a>
</nav>
```

#### `style.css`
```css
.menu {
    display: flex;
    gap: 15px;
}

.menu a {
    text-decoration: none;
    color: darkblue;
    font-weight: bold;
}
```

Тепер посилання стоять не стовпчиком, а в один ряд.

---

### 8. Картки через Flexbox

Картки — це блоки з короткою інформацією. Наприклад:
- улюблені ігри;
- тварини;
- фільми;
- хобі.

#### `index.html`
```html
<section>
    <h2>Мої улюблені ігри</h2>
    <div class="cards">
        <div class="card">
            <h3>Minecraft</h3>
            <p>Я люблю будувати світи.</p>
        </div>

        <div class="card">
            <h3>Roblox</h3>
            <p>Там багато різних режимів.</p>
        </div>

        <div class="card">
            <h3>Brawl Stars</h3>
            <p>Мені подобаються швидкі бої.</p>
        </div>
    </div>
</section>
```

#### `style.css`
```css
.cards {
    display: flex;
    gap: 20px;
}

.card {
    background-color: white;
    padding: 20px;
    border-radius: 14px;
    width: 200px;
    box-shadow: 0 4px 10px rgba(0, 0, 0, 0.1);
}
```
